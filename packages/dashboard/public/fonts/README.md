# Fonts

IBM Plex Sans Condensed and IBM Plex Mono, self-hosted.

Latin subsets only, in `woff2` — seven files, about 100KB in total. They are
committed rather than fetched from a CDN so the dashboard renders identically
with no network, which matters for a tool that is meant to work during an
incident.
